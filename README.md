# Student HelpDesk AI

Cloud-based, multi-agent AI Student Help Desk — Next.js + FastAPI + PostgreSQL
+ LangGraph/LangChain + RAG, built docker-first for local dev and AWS-ready
for production.

See `project-management/architecture.md` for the full system design and
`project-management/task_board.md` for current progress. Coordination
protocol for the multi-agent build is documented in `TEAM_PROTOCOL.md`.

## Quick start (once docker/docker-compose.yml lands — DEVOPS-01)
```
docker compose -f docker/docker-compose.yml up
```
